# Why RAMX fits Open Innovation

Most laptops spend the day with gigabytes of RAM and GPU memory sitting idle, yet the AI models people want to run are too large for any single one of them. RAMX turns that idle memory into a shared resource: each laptop contributes only the slice it can spare, even a few gigabytes, and holds a few layers of the model, so several ordinary machines together serve a model that none of them could load alone. Apple laptops (MLX) and NVIDIA laptops (FP8) join the same pipeline, so the hardware people already own becomes inference capacity, with no data centre and no new GPUs. Distributed inference tools exist, but they stop at the cluster: they do not answer who may join, who gets paid, or how anyone can check the accounting. RAMX adds that missing layer and makes idle consumer memory an open, paid, auditable market.

NEAR is what makes that market open instead of run by one company. Anyone can join with a NEAR account, people and AI agents pay per request in USDC with x402, and every balance change is signed and written to a NEAR contract, so anyone can verify the accounting without trusting the operator. Providers are paid from an on-chain Merkle payout contract, agents can be limited by an escrow contract the chain enforces, and a NEAR AI Cloud TEE model spot-checks answers so an open pool cannot be cheated for free. The result is a new kind of public utility: an OpenAI-compatible API backed by the spare memory of everyday laptops, where contributing, paying, earning and checking all happen in the open on NEAR.
